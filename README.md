# SPI-отладчик

Данные проект направлен на создание устройства на основе ПЛИС для отладки интерфейса SPI.

## Состав

В состав входит:

1. Само устройство;
2. Desctop программа на Java, показывающая пользователю байты переданные по SPI.

## Принцип работы

Устройство подключается к ПК с помощью USB разъёма и ведёт общение по COM-порту.

Вторым выходом устройство подключается к SPI-интерфейсу.

При детектировании тактового сигнала SCL, а также данных на линиях MISO/MOSI. Устройство передаёт пришедшие данные в COM-порт с пометками о текущем CS и линии передачи.

P.S. Также предпологается дополнительная возможность принудетельной выдачи данных на линии MISO/MOSI.
